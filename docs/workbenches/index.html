What a WorkBench is

A WorkBench is a fully prepared workspace setup packed into one install. Inside one bundle: extensions, capsules, a theme, templates, snippets, starter pages and a settings snapshot. Installing one configures the whole clinic workspace in a single step — the boards, the pages, the look, the note formats and the defaults all land together, matched to how a clinic like yours works.

Where a single extension adds one tool, a WorkBench assembles the entire setup — and it is still one confirm before anything lands. It also draws a hard line: a WorkBench configures the workspace and never touches patient records. The full guide keeps a matching WorkBenches section.

Extensions

Small tools that add features — automation, calculators, letters. The bundle lists every one it installs and how it starts out.

Capsules

Ready-made boards and sections — appointment book, recall board, claims, lab jobs — that the starter pages call into.

Theme

A new look for the whole workspace: colors, fonts, density and shape, applied on install and reverted just as easily.

Templates

Pre-written clinical notes, letters and forms — intake sheets, refraction notes, Rx pads, referral and payer letters.

Snippets

Small interface tweaks — heading sizes, sidebar density, chairside numerals, print output — applied from the settings snapshot.

Starter pages

Ready dashboard pages that wire the boards into a working day — the parts you actually look at while seeing patients.

Settings snapshot

The bundle's editor, appearance, quick-actions and extension settings, applied with the rest so the workspace behaves as designed.

The Solo Optometrist WorkBench

The curated WorkBench that ships with the platform. Built and reviewed by CaseX Labs.

The Solo Optometrist WorkBench is the complete one-chair practice in one install. Nine Solo pages carry the clinical loop — the morning cockpit, patient flow, the refraction and exam hub, dispensing and orders, billing and day close — while five Clinic boards cover the money and the suppliers: claims and TPA, inventory, lab jobs, purchase orders and the comms log. Recall campaigns, the inventory board and Stock Alerter run the follow-up and reorder automation; the chairside quick reference holds the conversion tables, triage patterns and drop protocols; and thirteen templates put the notes, letters and Rx pads a solo clinic writes every week one tap away. Everything sits on the calm Solo Optometry theme — white paper, ink text, electric-blue actions.

Counts match the bundle exactly: 10 extensions, 28 capsules, 1 theme, 13 templates, 7 snippets and 14 starter pages — 73 pieces in one install, plus the settings snapshot. One extension ships switched off: FocusCaseX SBL installs disabled because the Solo starter pages are the workspace chrome; enable it any time under Settings → Extensions if you prefer the sidebar-left layout. Re-applying the WorkBench updates extensions in place and creates starter pages only when missing — an existing page always wins, so your edits survive every re-apply.

Switching WorkBenches like modes

Every WorkBench you install becomes a mode of the workspace. The app's WorkBenches tab shows each installed WorkBench as a chip, and the active mode is highlighted — the workspace always tells you which setup you are running. Tap another installed WorkBench and one tap switches the whole workspace to that setup: the apply dialog is switch-aware, says what it is about to do before you confirm, then runs with progress as each piece lands and finishes with a final per-item summary.

Switch back and forth as often as the day requires. Modes are setups, not storage: nothing is deleted and your records stay put no matter how many times you change mode.

Installing a WorkBench — every path

Four ways in, one destination: each path ends on the app's in-app confirmation screen, which lists every piece the bundle adds before anything lands. One tap on Apply installs the whole setup.

a

Install from the website

Tap Install on a WorkBench page here — the marketplace page or the Solo Optometrist showcase. Your browser hands the WorkBench to the FocusCaseX app on this device, the app opens on the confirmation screen listing every piece, and you tap Apply.

b

Install by code

In the app, open Settings → Marketplace → Install by code and type the code. Same confirmation screen, same one-tap Apply.

FCX-2VJD2S
c

Install from file

Have a .workbench.json file — exported from another clinic or drafted by the WorkBench Builder? Open Settings → Marketplace → Install from file, pick the file, review the same confirmation screen and Apply.

d

From the CLI

Install the FocusCaseX CLI, inspect the WorkBench, then install it:

$curl -fsSL https://stromplayz.github.io/FocusCaseX/install.sh | bash
$fcx workbench show FCX-2VJD2S
$fcx workbench install FCX-2VJD2S

Full command reference: the CLI docs.

Build and share your own

Any clinic can turn its current workspace into a WorkBench. In the app, open Settings → Marketplace and tap Save current setup as WorkBench: FocusCaseX snapshots your extensions, capsules, theme, templates, snippets, pages and portable settings into one bundle. Download it and hand the file to a colleague or a second branch — they install it in one step, through any of the paths above. The snapshot is setup only; nothing from your patient records goes into the bundle.

Save the snapshot

Download the file

The bundle downloads as a .workbench.json file — yours to keep, review and version.

Hand it over

A colleague or a second branch installs the same setup in one step — the whole workspace, ready to work.

Not at a workspace worth saving yet? The WorkBench Builder on the MCP & Automation page can draft a starter bundle from a plain description of how your clinic works — how the day flows, what the desk needs to see — and you refine from there. Curated WorkBenches live in the WorkBenches section of the marketplace.

The boundary

A WorkBench is setup only.

Applying a WorkBench never deletes anything and never moves patient records. It adds tools, pages and settings; your case files, documents and history stay exactly where they are. The confirmation screen lists every piece before anything lands, and anything a WorkBench installs can be removed later under Settings, piece by piece.
