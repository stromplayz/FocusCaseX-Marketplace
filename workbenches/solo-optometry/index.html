The bundle file

One JSON, portable and inspectable.

The whole WorkBench is a single JSON file — the same file the app installs and the same file Save current setup as WorkBench produces. Open it, diff it, share it: workbenches/solo-optometry/workbench.json.

WorkBenches switch like modes After this WorkBench is applied it appears in Marketplace → WorkBenches as the active mode. Tap another WorkBench chip to shuffle the whole workspace to that setup — extensions, capsules, theme, templates and pages re-configure in one confirmed step.
Your records stay in the vault WorkBenches carry setup, never data. Applying a mode never deletes anything and never reads patient records — starter pages are created only when missing.
Save your own and share it Once the workspace is the way you want it, Settings → Marketplace → Save current setup as WorkBench packs it into the same JSON shape — ready for a second branch or a colleague.
