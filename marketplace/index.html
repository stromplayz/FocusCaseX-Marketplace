MCP & Automation

Your records, your AI agents —
with permission, not luck.

FocusCaseX hosts its own MCP server. Connect Claude, Cursor or any MCP agent — pair it with a 6-digit code or a QR scan, and it reads the clinic freely while every write shows a diff and waits for your approval. Revoke any time.

Approval first

Every agent asks before it gets in — a 6-digit code shown in-app, or a QR you scan. Approve once and the agent is bound to your install with the scopes you chose.

Read free, write on approval

Agents read the clinic freely. Every write — bookings, notes, installs — shows a human-readable diff and applies only on your Approve, nothing beyond the tools documented on the MCP page.

Full log, one-tap revoke

Every agent action is logged with time, agent and tool. Under Settings → MCP & Automation you can revoke any agent the moment something looks off.
