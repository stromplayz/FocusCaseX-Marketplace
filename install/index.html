Install guide

How to install

Three ways in today — the terminal registry and the Android app, with desktop and iOS on the way.

One command puts the FocusCaseX registry on any computer; the Android app carries the clinic in your pocket; this site installs add-ons straight into the app.

Platforms

Choose your platform

Two supported installs today — both open the same clinic, with the same catalog and the same FCX- install codes.

Recommended

Terminal

curl -fsSL https://stromplayz.github.io/FocusCaseX/install.sh | bash

Any machine with Node 18 — macOS, Linux, or Windows via WSL/Git Bash. Installs the fcx command, the marketplace and the clinic registry host.

What it does
  • Checks for Node 18 or newer before anything else.
  • Installs the fcx command to ~/.focuscasex/bin.
  • Wires that folder into your PATH for future terminals.

First steps and the command reference

Android

The clinic app for phones and tablets. Sign in with your licence email and password; a new device asks once for the FCX- device code from your licence email.

  1. Download the latest FocusCaseX build — the FocusCaseX v2.9.0 APK — to the device.
  2. When Android asks, allow installs from that source — a one-time switch the system remembers.
  3. Open the downloaded file, then open FocusCaseX from your app list.

For tech people

Install on any computer — the FCX CLI

The same marketplace, workbenches and MCP setup — installable anywhere Node 18 runs, hosted on your own machine.

Install once

Node 18 or newer, then one command in a terminal:

curl -fsSL https://stromplayz.github.io/FocusCaseX/install.sh | bash

Run the same command again to update — it replaces the binary in place. To remove it, run the installer with --uninstall; your data under ~/.focuscasex stays.

First steps

  1. Run fcx setup — guided setup: pick the workspace folder, sync the catalog, sign in.
  2. Run fcx marketplace — browse and install Extensions from the terminal.
  3. Run fcx status — confirm the device licence.

Same features as Android

  • Same catalog, same install codes — every item keeps its FCX-XXXXXX code.
  • WorkBench install with a per-piece summary, like the app's confirm dialog.
  • Local registry hosting for the clinic LAN.
  • MCP agent setup helper for AI agents.
  • Stays updated from the same marketplace — both ends move together.

Inside the app — three ways to install an add-on

Once FocusCaseX runs on a device, every add-on lands the same three ways — all one tap, and the FCX- install code works on every platform.

WAY 1 — IN THE APP

Search the Marketplace

The full catalog ships inside the app. Open it, find it, tap Install.

  1. Open FocusCaseX → Settings → Marketplace.
  2. Search, or browse Extensions, Capsules, Themes, Templates.
  3. Tap Install — it appears in your workspace right away.
WAY 2 — BY CODE

Type the install code

Every add-on carries a short code (each item page shows it). Type it in the app and the item opens with its confirm dialog.

  1. Copy the code from any item page here — it looks like FCX-XXXXXX.
  2. In the app: Settings → Marketplace → Install by code.
  3. Type or paste it, confirm the item, tap Install.
Works with any code from the catalog — try one from an item page.
WAY 3 — FROM THIS SITE

Tap Install, confirm in the app

On any item page, the install button hands the add-on straight to the FocusCaseX app on this device — the app asks you to confirm, then installs it. Nothing to download.

  1. Open an item page and tap Install — open the app.
  2. Your browser opens FocusCaseX and shows the item with a confirm dialog.
  3. Tap Install there — done. (Needs FocusCaseX installed on this device.)

If the app isn't on the device, a fallback panel shows the install code instead — type it in the app later (Way 2).

Remove any time

Settings → Marketplace → Installed → tap Remove. Installing or removing never touches your patient records.

Questions

Do add-ons cost extra?
No. Every add-on in the catalog — Extensions, capsules, themes, templates — is included with your FocusCaseX plan. There is nothing separate to buy inside the marketplace.
Do I need this website to install anything?
No — the full catalog is inside the app under Marketplace. This site is for browsing ahead of time, previewing items live, and sharing links with your team.
How do I update or remove the terminal install?
Run the install command again — it replaces the fcx command in place with the current build. To remove it, run the installer with --uninstall: the command and the PATH entry go, and your data under ~/.focuscasex stays.
Will it work offline, like the rest of FocusCaseX?
Yes. Once installed, add-ons work on your device with no internet, same as your records.
Who makes these — can I trust them?
Most are built and reviewed by the CaseX team; the shield badge means reviewed. Every item shows its author, version and last-update date.
What's the difference between extensions, capsules and templates?
Extensions add features, capsules are ready-made page sections, themes change the look, and templates are pre-written clinical notes and forms.
The browser button didn't open the app — now what?
The app may not be installed on that device, or the browser blocked the hand-off. The fallback panel gives you the install code — type it under Settings → Marketplace → Install by code, or just search for the item by name.
Can my AI assistant install add-ons for me?
It can find them for you — connect your agent through MCP & Automation and ask it to sweep the marketplace. The install itself stays a one-tap human decision.
